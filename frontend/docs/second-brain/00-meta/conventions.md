# Conventions

- File names: lowercase kebab-case; dated notes start `YYYY-MM-DD-`; timeline notes are `YYYY-Www.md`.
- Links: `[[note-name]]` (Obsidian style). Paths in `sources` are relative to the note.
- Types: `note`, `decision`, `gotcha`, `pattern`, `timeline`, `meta`.
