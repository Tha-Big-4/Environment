# Second Brain — guide

- **Find something:** start at [[SUMMARY]] or [[INDEX]], or search the folder (`rg -i <word> docs/second-brain`).
- **After finishing a plan:** add a line to this week's `01-timeline/YYYY-Www.md`; add a `02-decisions/` note per real decision; add a `04-gotchas/` note per trap.
- **New module:** add `06-modules/<module>.md` linking its specs, plans, endpoint docs and design exports.
- **Agents:** the `second-brain` skill in `.claude/skills/` follows these steps.
