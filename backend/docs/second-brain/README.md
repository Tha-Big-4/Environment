# Second Brain

A wiki-linked knowledge base of the project: what was built when, why, what broke and how it was
fixed. It is a **distilled index that points back into** `docs/superpowers/`, `docs/reports/` and the
code. It does not replace them. Opens as an Obsidian vault (open `docs/second-brain/`).

## If you are an AI agent, load in this order

1. [[RULES]]: the hard rules for reading and extending this brain.
2. [[SUMMARY]]: one-screen state of the project.
3. [[INDEX]]: every folder and note.
4. [[GUIDE]]: how to use it.
5. The folder you need; follow `[[wiki-links]]`; go to each note's `sources` for detail.
