# Second Brain — rules

1. **Distil, link, don't copy.** A note is a few lines plus `sources` pointing to the full detail.
2. **Frontmatter on every note** (`templates/second-brain-note.md`): title, folder, type, status, updated, sources, links.
3. **One note, one idea.** Split a note that covers two things.
4. **Link both ways.** When you link A → B, add A to B's `links`.
5. **Update the folder `SUMMARY.md`** and [[INDEX]] when you add, rename or remove a note.
6. **Update after work, not during.** When a plan moves to `finished/`, add the timeline entry, any decisions and any gotchas.
7. **Facts are dated.** A note that can go stale says when it was last true (`updated`).
8. **No secrets, no personal data.** This folder is in a public repo template.
