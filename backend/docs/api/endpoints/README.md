# Endpoint docs

One Markdown file per finished endpoint, named after what it does (`Create Task.md`), in a folder per
module (`endpoints/tasks/`). Start from [`_TEMPLATE.md`](_TEMPLATE.md). Shared response shapes go in
`_Shared - <Name>.md` inside the module folder.

Each module folder keeps a `SUMMARY.md` listing its endpoints, one line each:
`| Method + route | Doc | Since |`.
